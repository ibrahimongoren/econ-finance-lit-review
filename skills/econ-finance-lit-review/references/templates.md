## 0. Intake messages

Ask for the research question first and nothing else; ask for details only once the question
is clear. Skip a step whose answer the user already gave (restate what you understood
instead), and never ask twice. If nobody answers, take the defaults, record them under
*Assumptions* in `00_protocol.md` and continue.

**Step 1 — TR**
```
Bu konuda kapsamlı ve doğrulanmış bir literatür taraması yapacağım. Önce tek bir şey rica
ediyorum: net araştırma sorunuz nedir? (Tek cümle yeterli.)
Soru henüz netleşmediyse konuyu yazın; size 2–4 soru önerisi sunayım.
```

**Step 1 — EN**
```
I will run a comprehensive, verified literature review on this. First, one thing only:
what is your research question? (One sentence is enough.)
If it is not settled yet, give me the topic and I will propose 2–4 questions.
```

**Step 2 — TR** (after the question is clear)
```
Teşekkürler. Taramayı sorunuza göre ayarlamak için birkaç ayrıntı (boş bıraktıklarınızda
varsayılanı kullanırım):
1. Yıl aralığı — varsayılan: son 5 yıl (2021–2026)
2. Değişkenler: bağımlı, temel açıklayıcı ve kontrol değişkenleri
3. Veri: frekans, dönem, kaynak
4. Ülke / bölge
5. Yöntem ilginiz: ekonometrik, makine öğrenmesi / yapay zekâ, karşılaştırma
6. Bildiğiniz temel çalışmalar (varsa)
7. Erişiminiz: Web of Science / Scopus / ScienceDirect (üniversite), Zotero, Consensus /
   Elicit, API anahtarları — varsa dışa aktarım dosyası yükleyebilirsiniz
8. Çıktı: bağlantılı sohbet özetleri her zaman; ayrıca rapor: yok / DOCX / PDF / ikisi; dil
```

**Step 2 — EN**
```
Thanks. A few details to fit the search to your question (blank = default):
1. Years — default: the last 5 years (2021–2026)
2. Variables: dependent, key explanatory and control variables
3. Data: frequency, period, source
4. Countries / regions
5. Methods of interest: econometric, machine learning / AI, comparison
6. Key papers you already know (if any)
7. Your access: Web of Science / Scopus / ScienceDirect (institutional), Zotero, Consensus /
   Elicit, API keys — you can upload export files
8. Output: chat summaries with links always; plus a report: none / DOCX / PDF / both; language
```

## 1. Working-file schemas and conventions

`scripts/init_review.py` writes these headers (the list lives in
`scripts/litrev_common.py`). Without Python, create the CSVs by hand with exactly
these columns so the scripts work later.

| File | Columns |
|---|---|
| `01_seeds.csv` | seed_id, title, authors, year, doi, role, found_by |
| `02_search_log.csv` | query_id, date, source, query_string, filters, hits, retrieved, notes |
| `03_records.csv` | record_id, source, query_id, title, authors, year, venue, volume, issue, pages, doi, url, type, language, abstract, notes |
| `04_screening.csv` | record_id, stage, decision, reason_code, note |
| `05_verification.csv` | ref_id, record_id, status, confidence, method, link, link_check_method, checked_on, authors, year, title, venue, volume, issue, pages, doi, type, series, number, publisher, language, retracted, published_version_doi, online_year, evidence_level, discrepancy_note |
| `06_extraction.csv` | ref_id, theme, country_region, sample_period, frequency, unit, data_source, method_family, identification, outcome, key_regressors, direction, magnitude_units, uncertainty, location, heterogeneity, robustness, limitations, evidence_level, notes |
| `06_estimates.csv` | est_id, ref_id, estimate, se, t, df, effect_type, outcome, unit, horizon, sample, location, include, notes (+ numeric moderator columns) |
| `06_fulltext.csv` | ref_id, doi, oa_url, oa_source, version, license, checked_on, notes |
| `06_study_cards.csv` | ref_id, theme, pass1_abstract_conclusion, pass2_intro_method, pass3_literature, what_it_did, what_it_left_out, relevance, full_text_source, evidence_level, card_status, notes |
| `06_weaknesses.csv` | ref_id, category, severity, weakness, evidence_location, basis, notes |
| `07_appraisal.csv` | ref_id, identification, data, inference, robustness, transparency, relevance, total, venue_info, venue_source, venue_checked_on, notes |

Generated by scripts: `03_records_part-<Source>.csv` (search_sources / import_records),
`03_records_dedup.csv`, `03_duplicates.csv`, `03_coverage.md`, `04_rescreen.csv`,
`04_prisma_counts.json`, `04_prisma_flow.png/.svg`, `08_meta/meta_summary.md`,
`08_meta/meta_results.json`, `08_meta/funnel_*.png`, `10_figures/*.png`,
`10_report_full.md`, `10_report.docx`, `10_report.pdf`, `evidence_workbook.xlsx`.
`init_review.py` also writes the `10_report.md` skeleton (`reporting.md` §2). Card fields,
weakness categories and severities are defined in `study-cards.md`.

Conventions
- `authors`: `Family, Given; Family, Given` — the full byline (APA lists up to 20).
  Group authors as written (`PRISMA-S Group`). Never end with "et al.".
- `source` (03): the tool or site (`Crossref`, `Consensus`, `WebSearch:nber.org`). For
  routes outside database searching start with `snowball-backward`,
  `snowball-forward`, `author`, `seed`, `prior-review` or `user`, so PRISMA counts them
  as other methods.
- `record_id`: unique across all files; parallel workers prefix theirs (`A-001`).
- `type`: journal-article, working-paper, preprint, report, book, book-chapter,
  conference-paper, thesis, other.
- `stage` (04): `ta` or `ft`; `decision`: include, exclude, maybe, not_retrieved;
  `reason_code`: the protocol's E-codes (E7 = outside the literature window, written by
  `screening_check.py window`).
- `status` (05): VERIFIED, PARTIAL, PREPRINT, NOT_VERIFIED, RETRACTED. `year` is the
  issue year of the version of record; a different online-first year goes in
  `online_year`.
- `ref_id`: citekey such as `Andrews2019`; add `a`/`b` for clashes. Both reports of
  one study share the journal version's `ref_id` in 06–07.
- `references/example_verification.csv` is a filled, verified example.

## 2. Checkpoint messages (C1–C3)

Keep each to one screen: counts first, decisions taken, what comes next. These are
progress reports; stop and wait only in the cases listed in SKILL.md §2.

**C1 — protocol (EN)**
```
Protocol ready (00_protocol.md).
RQ1: … · RQ2: … · RQ3: …
Window: 2021–2026 (default: last five years) · Scope: … · Languages: …
Search routes: OpenAlex, Crossref, Semantic Scholar (API) · Consensus, SciSpace (connectors) ·
Scopus export (you) · NBER, IMF, BIS, ECB, TCMB series (web) · Mode: comprehensive
Defaults taken: working papers included; APA 7; report: DOCX + PDF.
Next: evidence scan and seed set, then the search.
```

**C2 — included set (EN)**
```
Searching and screening done. Identified N → N after de-duplication → N full texts
assessed → N included (N studies). Seed recall N/N; saturation reached after N queries.
Screening consistency: kappa 0.NN on 40 re-screened records.
Included by theme: … Borderline calls made: …
Next: verification, full texts and a card for each of the N studies (three passes, what it
did, what it left out, weaknesses).
```

**C3 — cevaplar ve sentez taslağı (TR)**
```
AS1: … (kesinlik: Orta) · AS2: … (Düşük)
Sentez taslağı: 4 tema, 2 yöntemsel ayrışma; meta-analiz: N tahmin, N çalışma.
Boşluklar: …
Sırada: raporun tam metni, kaynakça ve denetimler.
```

## 3. Report skeleton — English

The illustrated DOCX/PDF build uses the compact skeleton that `init_review.py` writes to
`10_report.md` (`reporting.md` §2). Use this fuller outline for a thesis chapter or a journal
submission.

```
Title
Answers to the research questions        (one block per RQ — synthesis.md §1)
Abstract (150–250 words) · Keywords · JEL codes
1. Introduction — question, why it matters, scope, contribution, plan
2. Methods
   2.1 Protocol, research questions and eligibility criteria
   2.2 Sources, languages and search strings (Appendix A)
   2.3 Coverage: seed recall and stopping rule
   2.4 Screening, consistency check and PRISMA 2020 flow (Figure 1)
   2.5 Reference verification (Appendix B)
   2.6 Extraction, appraisal and certainty grading
   2.7 Quantitative synthesis (if any)
   2.8 Limitations
3. Findings by theme (argument-led)
4. Methods comparison (table) and evidence map
5. Quantitative synthesis and publication bias
6. Discussion — consensus, disagreement and its sources
7. Research gaps and agenda
8. Conclusion
References (generated from the verification log, with links)
Appendices — A search log · B verification log · C included-studies table ·
D full-text exclusions with reasons · E unverified sources (not used as evidence)
```

For a central-bank, IFI or policy audience, add a one-page summary (key messages,
certainty, implications) before the introduction and move method detail to an annex.

## 5. Methods-section wording

**EN — search and coverage**
> We searched [sources] in [languages] between [dates] with the strings in Appendix A,
> retrieving up to [N] results per query, and complemented the search with backward
> and forward citation chasing of the core studies. The search was judged complete
> when every one of [k] pre-specified seed studies had been retrieved and the last
> three queries added fewer than 5% new included studies.

**EN — screening and verification**
> One reviewer screened titles and abstracts and then full texts against the criteria
> in Section 2.1. A blind re-screen of a stratified sample of [n] records gave Cohen's
> kappa of [κ] (Cohen, 1960). Every included study and every cited source was verified
> against an authoritative record — Crossref or OpenAlex for works with DOIs, the
> publisher's or series' official page otherwise — requiring title, first author, year
> (±1, reason recorded) and venue to agree; every printed link was resolved during the
> review and logged with its date. Unverifiable sources are listed in Appendix E and
> were not used as evidence.

**TR — tarama ve kapsam**
> [Kaynaklar] [diller] dilinde, [tarihler] arasında Ek A'daki dizgelerle taranmış,
> sorgu başına en fazla [N] sonuç incelenmiş ve çekirdek çalışmaların geriye ve ileriye
> atıf zincirleri izlenmiştir. Önceden belirlenen [k] tohum çalışmanın tamamı
> yakalandığında ve son üç sorgu dahil edilen çalışmalara %5'ten az yeni katkı
> yaptığında tarama tamamlanmış kabul edilmiştir.

**TR — eleme ve doğrulama**
> Başlık/özet ve tam metin elemesi Bölüm 2.1'deki ölçütlere göre tek değerlendirici
> tarafından yapılmış; [n] kayıtlık tabakalı bir örneklemin kör yeniden elemesinde
> Cohen kappa değeri [κ] bulunmuştur (Cohen, 1960). Dahil edilen ve atıf yapılan her
> kaynak yetkili bir kayda karşı doğrulanmıştır: DOI'si olanlar için Crossref veya
> OpenAlex, diğerleri için yayıncının ya da serinin resmî sayfası. Eşleşme için başlık,
> ilk yazar, yıl (±1, gerekçesiyle) ve yayın yeri ölçütlerinin dördü de aranmış; basılan
> her bağlantı tarama sırasında çözümlenip tarihiyle kaydedilmiştir. Doğrulanamayan
> kaynaklar Ek E'de listelenmiş ve kanıt olarak kullanılmamıştır.

Thesis (placeholder fields — fill from the thesis record):

## 7. Update report

```
Update of: [title] · previous search: YYYY-MM-DD · this search: YYYY-MM-DD
New records: N → new included studies: N (list with one line each)
Changed answers: RQ1 unchanged (certainty Moderate → Moderate); RQ2 … (Low → Moderate, because …)
Meta-analysis: PET-PEESE estimate from X (SE) to Y (SE); N → N estimates
New or closed gaps: …
Updated PRISMA flow and evidence workbook attached.
```
